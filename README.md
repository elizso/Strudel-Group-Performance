# Sound and Music Computing: LENS Performance Repository

<https://comp.anu.edu.au/courses/comp4350/assessments/lens-performance/>

This repository is for you to submit your LENS Performance assessment for Sound and Music Computing.

If you're a student in Sound and Music Computing, there are a few things you need to do to get started.

## Steps to submit your LENS Performance

1. The LENS Performance assessment is complicated, make sure you [**read the entire assessment description**](https://comp.anu.edu.au/courses/comp4350/assessments/lens-performance/), then,

2. fork this project to your own "uid" [GitLab](https://gitlab.cecs.anu.edu.au/) account

3. when you fork it, make sure that you don't change the name

4. add all materials (patches, code, sound files, scores, instructions) needed for your performance to the `materials` directory.

5. document your performance materials and references in `documentation-and-reference.md` (N.B., not this readme file, the other markdown file).

6. complete your ensemble performance recording session

7. add your LENS performance video as the file `lens-performance.mkv`

8. commit & **push** it all to GitLab

_Note_: you can push as many times as you like and all versions are backed up on GitLab with the time and date that you pushed it. Push early and push often.

## Getting help

If you have any questions or problems, ask in consultation time after your workshop or on the course forum.
